    04 · 常见问题

    FAQ

    这个页面如何知道 ChatGPT 和 Claude 实际看到的 IP？

    ChatGPT、Claude 以及大多数主流 AI 平台都接入了 Cloudflare，其域名下开放了支持 CORS 的 /cdn-cgi/trace 接口。您的浏览器会沿当前真实网络路由直接请求该接口，因此即便配置了复杂的分流规则，也能准确显示每个平台看到的出口 IP 和地区。

    直连路由显示的地区和 ChatGPT 不一样，这算泄露吗？

    不算，这是正常的 分流（Split-tunneling）：国内/本地流量直连，AI 域名走海外节点。只要同一平台（如 OpenAI 或 Anthropic）的所有子域名共享同一个受支持地区节点，且没有 WebRTC/DNS 泄露，分流是完全健康的。

    为什么 OpenAI 或 Claude 的不同子域名有时显示不同 IP？

    某些代理规则会对不同域名做负载均衡或走了不同策略组。如果 chatgpt.com 与 api.openai.com 从不同 IP 甚至不同国家出口，反风控可能会判定为异地同时登录。建议将同一平台的所有域名固定到单个稳定节点。

    AlfaFond 会记录或保存我的 IP 吗？

    不会。本站是部署在 GitHub Pages 上的纯静态 HTML/JS 页面，没有后端服务器和数据库。历史对比记录仅存储在您本机浏览器的 localStorage 中。
